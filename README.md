# Randomiser

**A collection of useful everyday tools, all in one place.**

Randomiser is a macOS app built with SwiftUI, designed to bring together handy utilities in one simple, easy-to-use application.

## Download

[**Download the latest version of Randomiser**](https://github.com/john-walker123/RandomiserApp/releases/latest)

Visit the [Releases](https://github.com/john-walker123/RandomiserApp/releases) page to view previous versions and their release notes.

## Installation

1. Download the latest `Randomiser.Installer.dmg` from Releases.
2. Open the downloaded DMG file.
3. Drag **Randomiser** into the **Applications** folder.
4. Open Randomiser from Applications.

## Features

Randomiser brings together a growing collection of everyday utilities.

The app is continuously being improved, with new tools, features and enhancements introduced over time.
