# RandomiserApp

My first SwiftUI application! A collection of four simple interactive tools built using SwiftUI.

## Features

- 🎲 **Dice Roller** – Roll a virtual six-sided dice.
- 🪙 **Coin Flipper** – Flip a coin to get heads or tails.
- 🔢 **Random Number Generator** – Generate a random number within a custom range.
- 💱 **Currency Converter** – Convert between currencies using a custom conversion rate.

## Built With

- Swift
- SwiftUI
- Swift Playgrounds

## About

This is my first app development project. I built it to practise SwiftUI, state management, navigation, computed properties and user interaction.
